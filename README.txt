RCX MEDIX, LLC WEBSITE — VERCEL STATIC DEPLOYMENT

Files:
- index.html: main page
- styles.css: responsive layout, colors, animation styling
- script.js: mobile menu, reveal animations, current copyright year
- assets/rcx-mark.jpg: cropped symbol from the supplied logo
- vercel.json: simple Vercel static-site configuration

DEPLOY:
1. Extract this ZIP on your computer.
2. Upload the CONTENTS of this folder to the ROOT of a GitHub repository (not the containing folder).
3. In Vercel, import that repository and deploy with Framework Preset = Other.
4. Leave Build Command empty and Output Directory empty (or default/root).
5. Connect your domain in Vercel after deployment.
